# SamMeow AI 工作台 — 玩家使用指南

这份文档面向第一次使用本整合包的玩家。它假设你会解压文件、双击 bat、用浏览器，但不要求你会命令行或了解 AI 接口。

> 几个会反复出现的词，先用大白话解释一次：
>
> - **服务商**：提供 AI 模型的公司（例如 DeepSeek、Kimi）。
> - **模型**：AI 的"大脑"。同一家服务商可能有多个模型，能力和价格不同。
> - **API key**：服务商发给你的通行证，通常以 `sk-` 开头。
> - **人格**：AI 平时跟你说话的语气设定。
> - **工作目录**：AI 实际读写文件的文件夹。

## 1. 这是什么

一个开箱即用的 AI 编程环境（opencode + 插件全家桶）。你负责用中文描述需求，AI 负责写代码。解压后双击一个 bat 就能用，不需要安装任何东西。

使用前需要满足：

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 2004 及以上 |
| 网络 | 首次配置需要联网；之后每次和 AI 对话也需要联网 |
| 权限 | 一般权限即可，通常不需要管理员 |

包内有两个入口：

- `启动.bat`：主入口。没配置过会先打开配置页；配置过就直接进入工作台。
- `进入环境.bat`：只打开一个已经准备好的环境窗口，不启动 opencode。

> 解压位置：请在 D:\ 或 E:\ 根目录下**新建一个文件夹**再解压，不要直接解压到盘符根目录（如 C:\ 或 D:\ 根），路径也不要太深、不要带空格。

## 2. 五分钟上手

1. 解压到上一条建议的位置。
2. 双击 `启动.bat`。
3. 浏览器自动弹出"QDIP 首次配置"页：勾选你想用的服务商 → 粘贴 API key → 点"测试连接"，看到"连接成功，可以保存了"。
4. 点"保存配置"，页面出现"配置完成"后关闭浏览器。
5. 重新双击 `启动.bat`，进入工作台。

细节说明：

- 第 3 步如果浏览器没有自动弹出，等 3 秒再双击一次 `启动.bat`。
- 默认用整合包自带的 Windows Terminal 打开工作台（显示效果更好）。如果系统里缺少它，程序会自动改用经典控制台窗口，不需要你设置。
- 想强制使用经典控制台窗口，需要用带参数的方式运行 `启动.bat --console`（怎么带参数见第 6 节）。

## 3. 首次配置逐项说明

配置页完全在本机运行，key 只保存在你自己的电脑上，不会上传到任何其他地方。

> 如果你之前配置过、又再次打开了这个页面，页面顶部会出现"检测到本机已有配置。重新保存会覆盖旧的 key。"。这时保存会用新内容覆盖旧配置。

### 服务商卡片

页面上有 4 张精选服务商卡片（"精选"= 整合包已经帮你填好接口地址的服务商）。**先勾选卡片**，下面的 key 输入框和"测试连接"按钮才会变成可用状态。

| 卡片 | 适合谁 |
|---|---|
| DeepSeek（带"推荐"标签） | 国产模型，价格便宜，新用户注册送额度。不确定选哪个就选它。 |
| Kimi (Moonshot) | 月之暗面出品，国内可直接访问，长文本表现好。 |
| Kimi For Coding(编程版) | Kimi 编程订阅版：在 Kimi 官网开通 Kimi For Coding 后，用编程套餐的 API key。与上面的 Kimi(Moonshot)开放平台是两套独立服务，key 不通用。 |
| OpenAI | 需要能访问海外网络，账户需绑定海外支付方式。 |

[!] Kimi (Moonshot) 和 Kimi For Coding 是两套独立服务，key 不要混用：买了编程订阅就选"Kimi For Coding"，用开放平台的 key 就选"Kimi"。

### "测试连接"按钮做什么

点击后，程序会拿着你填的 key 去问服务商："这个 key 能用吗？"。这一步同时验证两件事：key 是否正确、你的网络能否连上对方服务器。测试期间按钮附近会显示"测试中，请稍等..."。

看到"连接成功，可以保存了"，说明这家服务商可以用了。

失败时会看到下面几种提示之一：

| 页面提示 | 含义 | 怎么办 |
|---|---|---|
| API key 无效，请检查有没有复制完整（401） | key 不对 | 重新复制以 `sk-` 开头的完整 key，确认没有多复制空格 |
| 账户余额不足，请先到服务商官网充值（402） | 账号没钱了 | 到服务商官网充值后再测 |
| 连不上服务商的服务器，请检查网络（或代理）后重试 | 网络不通 | 检查网络；如果开了代理，确认代理能访问该服务商 |
| 请先粘贴 API key 再测试 | key 是空的 | 先粘贴 key |

> 测试通过后又去改动 key，之前的测试结果会作废，并提示"key 已修改，请重新测试"。这是为了防止保存没验证过的 key。

### 为什么必须先测试通过才能保存

页面底部的"保存配置"按钮，在至少有一家服务商测试通过之前是灰色的，按钮旁边写着"至少有一个服务商测试通过后才能保存"。如果一家都没测就点，页面会提示"还没有测试通过的服务商：先勾选一家，填 key，点'测试连接'"。

这样做是为了避免把打错、复制不全或已欠费的 key 存进配置——存进去之后 AI 是连不上的，而且不会有明显提示。

保存成功后，页面会显示"配置完成：请关闭本页面，重新双击启动器，就可以开始使用了"。

### 三个可选项

配置页上的"AI 人格""模型分配""工作目录"三段都是**可选**的，不填也能保存。它们的作用分别见第 5、6 节。

## 4. 自定义服务商（可选）

### 什么时候用

精选的 4 家之外还想用别的服务时：

- 想用智谱、千问、豆包等国内服务商（只要对方提供 OpenAI 兼容的 API 地址）。
- 买了第三方 API 中转站，对方一般会给一个形如 `https://xxx.com/v1` 的地址。
- 电脑本地跑着 Ollama、LM Studio 等本地模型，完全免费、离线可用。

入口在服务商列表底部："+ 添加自定义服务商"。点一下会出现一张空白卡片。

### 四个字段怎么填

| 字段 | 说明 |
|---|---|
| 显示名 | 可选。给自己看的名字，例如"智谱"。测试通过后会显示在卡片标题上。 |
| Base URL | 必填。服务商给的接口地址，一般以 `/v1` 结尾（末尾斜杠可有可无）。 |
| API Key | 可选。云端服务必须填；本地服务（如 Ollama）可以留空。 |
| 模型 ID | 可选。端点没有返回模型列表时才需要手填，多个用逗号分隔（中英文逗号都可以）。 |

填好后点"测试连接"。这里比精选卡多一步：

- 如果端点返回了模型列表，卡片下方会出现"检测到的模型（默认全选，可取消不需要的）"，逐项勾选即可。勾选项和你在"模型 ID"里手填的会**合并去重**，一起作为这张卡的模型列表。
- 如果端点没有返回模型列表，会提示"连接成功，但端点未返回模型列表：请在'模型 ID'里手动填写后重新测试"。此时必须在"模型 ID"里手填至少一个模型才能保存。
- 测试成功后提示形如"连接成功 · 服务商标识: bigmodel · 模型 3 个"。

> 修改 Base URL、API Key 或显示名都会让这张卡的测试结果作废，需要重新测试；只改"模型 ID"或勾选项不需要重测。

### 服务商标识是怎么来的

保存时，系统会按 Base URL 的域名自动生成一个标识（可以理解成给这家服务商起的小名）：

- 取域名主名：`open.bigmodel.cn` → `bigmodel`，`api.zhipuai.cn` → `zhipuai`。
- 填 `localhost` 或 `127.0.0.1`（本地服务）→ `local`。
- 多张卡片撞名会自动加后缀：`bigmodel`、`bigmodel-2`、`bigmodel-3`。
- 测试通过后卡片标题会显示最终标识，例如"自定义 · 智谱 (bigmodel)"。以页面上显示的为准。

标识会自动避开精选服务商的名字（deepseek、kimi、moonshot、openai、kimi-for-coding）。如果派生出的名字撞上了精选卡，会出现黄色提示："检测到该地址与精选卡同名，建议直接使用上方精选卡；继续保存将以 xxx 注册"。这时建议直接改用上方对应的精选卡。

### 本地模型示例（Ollama）

电脑上装好 Ollama 并拉好模型后：

- Base URL 填 `http://localhost:11434/v1`
- API Key 留空
- 模型 ID：测试连接后如果端点返回了模型列表，直接勾选；否则手填本地模型名（在 Ollama 里执行 `ollama list` 查看，例如 `qwen2.5:7b`）

LM Studio 等同理，把它提供的 OpenAI 兼容地址填进 Base URL 即可。

> 自定义服务商测试通过后，这家服务的模型才会出现在下面"模型分配"的下拉列表里，可以像精选服务商一样直接选。

## 5. 人格与角色模型分配（可选）

### AI 人格

人格决定 AI 平时用什么口吻跟你说话。四选一：

| 选项 | 效果 |
|---|---|
| 专业默认 | 直接干活的实干型助手，标准工作口吻。**不写任何人格文件**。 |
| Vault-Tec 复古 | 1950 年代原子风企业终端口吻，有趣。 |
| 极简 | 一句话能说完绝不说两句。 |
| 自定义 | 自己写一段要求（例如"你是一位有耐心的老师，回答时喜欢举生活中的例子"），AI 会照着做。留空则不设置人格。 |

不确定就保持"专业默认"。

### 角色模型分配

工作台里的 AI 不是一个整体，而是分成若干"角色"，各干各的活。你可以给每个角色单独指定用哪个模型。三组共 10 个角色：

| 分组 | 角色 | 职责 |
|---|---|---|
| 核心角色 | orchestrator | 总指挥：拆解任务，给其他角色派活 |
| 核心角色 | oracle | 智囊：架构决策，攻克疑难问题 |
| 核心角色 | fixer | 执行者：写代码、修 bug |
| 辅助角色 | designer | 美工：界面样式与视觉 |
| 辅助角色 | explorer | 侦察兵：在代码库里找东西 |
| 辅助角色 | librarian | 资料员：查文档、查资料 |
| 辅助角色 | observer | 观察员：监督流程，提醒风险 |
| 议会 | council-alpha | 议会席位一：重大决策时参与投票 |
| 议会 | council-beta | 议会席位二：重大决策时参与投票 |
| 议会 | council-gamma | 议会席位三：重大决策时参与投票 |

每个角色右侧有一个下拉框：

- 第一项是"跟随默认"：表示这个角色用整合包预设的默认模型，不单独指定。**不确定就选它。**
- 其余选项是你已测试通过的服务商 / 模型组合。

两个快捷按钮：

- "全部跟随默认"：把所有角色都设回"跟随默认"。
- "全部用同一模型"：把所有角色都设成同一个模型（按钮上会显示具体模型名）。只配了一家服务商时用它最省事。

[!] 注意：如果全部选"跟随默认"，预设里用到了 DeepSeek 与 Kimi For Coding 两家服务，你就需要这两家的 key。只配了一家的玩家，请用"全部用同一模型"一键指定，避免部分角色无法工作。

## 6. 工作目录

工作目录 = AI 实际读写文件的文件夹。

默认情况下，AI 在整合包自己的根目录里干活。想让它改你的项目，就把工作目录换成那个项目文件夹。

### 三种改法

1. **首次配置时在引导页填**：配置页最下面的"工作目录"栏，填项目文件夹路径（例如 `D:\my-project`）。留空则默认在整合包目录启动。
2. **用 `启动.bat --workspace` 弹窗选择**：会弹出一个文件夹选择框，选完自动记住，下次启动生效。
3. **手工编辑**：用记事本打开 `data\workspace.txt`，把路径填进去保存。

> 怎么带参数运行 bat：双击 bat 不会传递参数。要使用 `--workspace` 或 `--console`，可以右键 `启动.bat` → 发送到 → 桌面快捷方式，再在快捷方式的"属性 → 目标"末尾加上空格和参数；也可以在该文件夹的地址栏输入 `cmd` 回车，然后在命令行窗口里执行 `启动.bat --workspace`。嫌麻烦的话，优先用第 1 种或第 3 种。

### 什么时候生效

改完要**重新启动**才生效：关掉工作台窗口，重新双击 `启动.bat`。在引导页里填的工作目录在保存时就写好了，同样是下次启动生效。

### 为什么建议一个项目一个文件夹

每个想法建一个独立文件夹（例如 `D:\我的项目\子弹价格修改器`），不要把多个项目混在一起。AI 会在当前工作目录里读写文件，项目隔离 = 修改互不干扰。

## 7. 日常用法与工作流建议

### 需求描述公式

好的需求 = 做什么 + 给谁用 + 边界。

- 差的：帮我写个工具
- 好的：做一个给 SPT 用的工具，把 mods 文件夹里所有 json 的 "price" 字段统一打 8 折，保留原始文件备份

### 先让 AI 给方案，再让它动手

第一次对话先说"先给我一个方案 / 计划"，确认方向后再说"按这个做"。方向错了返工的成本远高于多问一句。

### 看不懂就问，报错就贴

让 AI 解释它写的每一行代码，别怕问"这段是什么意思"。遇到报错，直接把报错文字复制给 AI，问"这个报错什么意思，怎么修"。不要自己猜，也不要重开新对话——同一对话里 AI 记得上下文。

### 不要把密钥贴给 AI

API key 是你的私人通行证，只需要填在配置页里。不要把它粘贴进对话内容、截图或分享给别人。配置页里的 key 只保存在你自己的电脑上。

### 重要东西随手备份

AI 写的代码也是代码，重要项目定期复制一份文件夹。工作台本身的重置很简单：删除 `data` 文件夹 = 回到初始状态（配置也重置）。

### 想再开一个 opencode

在 Windows Terminal 里直接新开标签页（Ctrl+Shift+T）：新标签默认就是 QDIP 环境（路径与配置已自动注入，也会记住工作目录），输入 opencode 回车即可。想开普通的 PowerShell / cmd，点标签页旁的下拉箭头选其它 profile。

在整合包自带的 Windows Terminal 窗口里，Ctrl+C / Ctrl+V 已绑定为复制粘贴，可以放心使用。

### 适合做什么

- 小工具 / 脚本（批量改文件、整理数据、自动下载）
- 游戏 mod 配置（改数值、加物品、调平衡）
- 学习编程（让 AI 解释它写的每行代码）
- 数据处理（CSV / JSON / Excel 转换）

### 不适合做什么（现阶段）

- 大型商业软件（涉及复杂架构的项目需要专业开发）
- 涉及别人账号密码 / 支付系统的程序（安全风险，别让 AI 写）

### 想继续深入

1. 用工作台写你的第一个小工具。
2. 学会看 AI 写的代码（让它注释每一行）。
3. 自己改 AI 生成的代码（从改一个数字开始）。
4. 加入 mod 开发社区，用这套环境写你的第一个 SPT mod。

## 8. 故障排查与更新卸载

### 常见问题

| 现象 | 原因与解决 |
|---|---|
| 双击 `启动.bat` 没反应 | 杀毒软件拦截了 bat，添加信任；或右键"以管理员身份运行" |
| 浏览器没弹出配置页 | 等 3 秒再双击一次；确认 `启动.bat` 所在路径没有中文嵌套过深 |
| 提示"引导服务启动失败" | 重试一次；检查杀毒软件是否拦截了引导服务，或关闭其他占用 127.0.0.1 端口的程序 |
| 引导页打不开 | 引导服务没能启动（它用系统随机分配的空闲端口，一般不会撞端口）：重试一次，并检查杀毒软件是否拦截；仍不行就删掉 `data` 文件夹后重新双击 `启动.bat` |
| 测试连接提示"API key 无效（401）" | key 复制不完整，或服务商后台未充值；重新复制以 `sk-` 开头的完整 key |
| 测试连接提示"账户余额不足（402）" | 到服务商官网充值后再试 |
| 测试连接提示"网络错误" | 本机无法访问该服务商 API（代理 / 防火墙限制）；检查网络后再试 |
| key 明明有效却连不上 | 多半是网络 / 代理问题：确认代理能访问该服务商；OpenAI 需要能访问海外网络 |
| 想用经典控制台窗口 / Windows Terminal 缺失 | 缺失时程序会自动回退到控制台，无需设置；想强制使用，用带参数方式运行 `启动.bat --console` |
| 人格不生效 | 先关掉工作台窗口、重新双击 `启动.bat` 再看；若仍无效，检查 `opencode\config\opencode\instructions\persona.md` 是否存在、`opencode\config\opencode\opencode.json` 的 `instructions` 里是否有 `{env:QDIP_PERSONA}`；都没有就删掉 `data` 文件夹重新配置 |
| 想换模型 / 换服务商 | 删掉 `data` 文件夹重新走一遍配置；或直接改 `opencode\config` 下的配置文件（建议改 `opencode\config\opencode\local\`） |
| 页面提示"信息已修改，请重新测试" | 正常现象，重新点一次"测试连接"即可 |

### 更新

- **只更新 opencode 本体**：双击 `更新组件.bat`（需要联网）。它会从官方源下载最新 opencode 替换 `opencode\bin\opencode.exe`；失败时会提示改用新版整合包 zip。
- **整包更新**：等新版整合包发布，下载新版 zip 解压覆盖到同一目录。想保留配置，更新时保留这两个目录：
  - `opencode\auth`（登录密钥 / API key）
  - `opencode\config\opencode\local`（你的本地修改区）

> 注意：`更新组件.bat` 只更新 opencode 本体；插件与技能包等随新版本整合包更新。

### 重置 / 卸载

- **重置**：删除整个 `data` 文件夹 = 回到首次配置状态（配置与 API key 也一起重置）。
- **卸载**：整合包是自包含的，所有东西都在这个文件夹里，直接删除整个文件夹即可。

### 确认包是完整的

用带参数方式运行 `启动.bat --check`。它会逐项检查 Node、opencode、插件、Windows Terminal、工作目录等，输出 `[OK]` / `[FAIL]` / `[WARN]` 清单。出现 `[FAIL]` 说明文件缺失或损坏，建议重新解压一份。
