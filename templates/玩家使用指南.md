# SamMeow AI 工作台 — 玩家使用指南

## 这是什么
一个开箱即用的 AI 编程环境（opencode + 插件全家桶）。你负责描述需求，AI 负责写代码。

## 快速开始（5 步）
1. 解压到任意文件夹（路径别带中文以外的问题：建议 D:\ 或 E:\ 根目录新建文件夹）
2. 双击 启动.bat
3. 浏览器弹出配置页：勾选模型服务商 → 粘贴 API key → 点"测试连接"（显示成功）
4. 点"保存配置"，关闭浏览器
5. 重新双击 启动.bat → 进入工作台

## 怎么高效使用（工作流建议）
### 1. 一个项目一个文件夹
每个想法建一个独立文件夹（比如 D:\我的项目\子弹价格修改器），不要把多个项目混在一起。
AI 会在当前文件夹里读写文件，项目隔离 = 修改互不干扰。

### 2. 先想清楚再开口（需求描述公式）
好的需求 = 做什么 + 给谁用 + 边界。
- 差的：帮我写个工具
- 好的：做一个给 SPT 用的工具，把 mods 文件夹里所有 json 的 "price" 字段统一打 8 折，保留原始文件备份

### 3. 让 AI 先给你方案，再让它动手
第一次对话先说"先给我一个方案/计划"，确认方向后再说"按这个做"。
方向错了返工的成本远高于多问一句。

### 4. 改不动了就说"看看哪里出问题了"
遇到报错直接把报错文字复制给 AI，说"这个报错什么意思，怎么修"。
不要自己猜，不要重开新对话——同一对话里 AI 记得上下文。

### 5. 重要东西随手备份
AI 写的代码也是代码，重要项目定期复制一份文件夹。
工作台本身的重置很简单：删除 data 文件夹 = 回到初始状态（配置也重置）。

## 适合做什么
- 小工具/脚本（批量改文件、整理数据、自动下载）
- 游戏 mod 配置（改数值、加物品、调平衡）
- 学习编程（让 AI 解释它写的每行代码）
- 数据处理（CSV/JSON/Excel 转换）

## 不适合做什么（现阶段）
- 大型商业软件（涉及复杂架构的项目需要专业开发）
- 涉及别人账号密码/支付系统的程序（安全风险，别让 AI 写）

## 常见问题
| 问题 | 解决 |
|---|---|
| 双击没反应 | 杀毒软件拦截了 bat，添加信任；或右键"以管理员身份运行" |
| 浏览器没弹出配置页 | 等 3 秒再双击一次；确认 启动.bat 所在路径无中文嵌套过深 |
| API key 无效 | 检查是否复制完整（sk- 开头）、服务商后台是否已充值 |
| 想换模型 | 删掉 data 文件夹重新配置，或直接改 opencode/config 下的文件 |
| 怎么更新 | 等新版整合包发布，解压覆盖（保留 opencode/auth 与 opencode/config/local 不丢配置） |

## 进阶成长路径
1. 用工作台写你的第一个小工具
2. 学会看 AI 写的代码（让它注释每一行）
3. 自己改 AI 生成的代码（从改一个数字开始）
4. 把 opencode 装进系统 PATH（安装到系统.bat），任何文件夹都能启动
5. 加入 mod 开发社区，用这套环境写你的第一个 SPT mod
