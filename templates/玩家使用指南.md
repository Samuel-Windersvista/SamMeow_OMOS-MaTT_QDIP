# SamMeow AI 工作台 — 玩家使用指南

## 这是什么
一个开箱即用的 AI 编程环境（opencode + 插件全家桶）。你负责描述需求，AI 负责写代码。

## 快速开始（5 步）
1. 解压到任意文件夹（路径别带中文以外的问题：建议 D:\ 或 E:\ 根目录新建文件夹）
2. 双击 启动.bat
3. 浏览器弹出配置页：勾选模型服务商 → 粘贴 API key → 点"测试连接"（显示成功）
4. 点"保存配置"，关闭浏览器
5. 重新双击 启动.bat → 进入工作台

> 提示：默认会用自带的 Windows Terminal 打开工作台（显示效果更好），需要 Windows 10 2004 及以上版本；若想用经典控制台窗口，运行 `启动.bat --console`。

> 工作目录：AI 默认在整合包根目录干活。想换到别的文件夹，双击 `启动.bat --workspace` 弹窗选择（选择会被记住，下次启动自动生效）；也可以手动编辑 `data\workspace.txt` 填路径。首次配置引导页里也有"工作目录"可填。

> 想再开一个 opencode？在 Windows Terminal 里直接新开标签页（Ctrl+Shift+T）：新标签默认就是 QDIP 环境（路径与配置已自动注入，也会记住工作目录），输入 opencode 回车即可；想开普通的 PowerShell / cmd，点标签页旁的下拉箭头选其它 profile。

## 怎么高效使用（工作流建议）
### 1. 一个项目一个文件夹
每个想法建一个独立文件夹（比如 D:\我的项目\子弹价格修改器），不要把多个项目混在一起。
AI 会在当前文件夹里读写文件，项目隔离 = 修改互不干扰。

### 2. 先想清楚再开口（需求描述公式）
好的需求 = 做什么 + 给谁用 + 边界。
- 差的：帮我写个工具
- 好的：做一个给 SPT 用的工具，把 mods 文件夹里所有 json 的 "price" 字段统一打 8 折，保留原始文件备份

### 3. 让 AI 先给你方案，再让它动手
第一次对话先说"先给我一个方案/计划"，确认方向后再说"按这个做"。
方向错了返工的成本远高于多问一句。

### 4. 改不动了就说"看看哪里出问题了"
遇到报错直接把报错文字复制给 AI，说"这个报错什么意思，怎么修"。
不要自己猜，不要重开新对话——同一对话里 AI 记得上下文。

### 5. 重要东西随手备份
AI 写的代码也是代码，重要项目定期复制一份文件夹。
工作台本身的重置很简单：删除 data 文件夹 = 回到初始状态（配置也重置）。

## 适合做什么
- 小工具/脚本（批量改文件、整理数据、自动下载）
- 游戏 mod 配置（改数值、加物品、调平衡）
- 学习编程（让 AI 解释它写的每行代码）
- 数据处理（CSV/JSON/Excel 转换）

## 不适合做什么（现阶段）
- 大型商业软件（涉及复杂架构的项目需要专业开发）
- 涉及别人账号密码/支付系统的程序（安全风险，别让 AI 写）

## 接入自定义服务商（可选）
页面自带的 DeepSeek / Kimi / Kimi For Coding / OpenAI 四家之外，还想用别的服务？点服务商列表底部的"+ 添加自定义服务商"即可，支持任意 OpenAI 兼容接口。

> 注意：Kimi For Coding（编程订阅，`api.kimi.com/coding`）在工作台里有专属卡片，和 Kimi (Moonshot) 开放平台不是同一个服务，key 不要混用。

### 什么时候用
- 想用智谱、千问、豆包等国内服务商（只要对方提供 OpenAI 兼容的 API 地址）
- 买了第三方 API 中转站（一般会给一个形如 `https://xxx.com/v1` 的地址）
- 电脑本地跑着 Ollama、LM Studio 等本地模型，完全免费、离线可用

### 各字段怎么填
| 字段 | 说明 |
|---|---|
| 显示名 | 可选，给自己看的名字，测试通过后会显示在卡片标题上 |
| Base URL | 必填，服务商给的接口地址，一般以 `/v1` 结尾（末尾斜杠可有可无） |
| API Key | 可选，云端服务必须填；本地服务（如 Ollama）可以留空 |
| 模型 ID | 测试通过后端点返回的模型会自动列出，勾选即可；只有端点不返回模型列表时才需要手填（多个用逗号分隔） |

### 本地 Ollama 示例
电脑上装好 Ollama 并拉好模型后：
- Base URL 填 `http://localhost:11434/v1`
- API Key 留空
- 模型 ID 填本地模型名（在 Ollama 里执行 `ollama list` 查看，如 `qwen2.5:7b`）

### 服务商标识是怎么来的
保存时系统会按 Base URL 的域名自动生成一个标识（类似给服务商起的小名），规则：
- 取域名主名，如 `open.bigmodel.cn` → `bigmodel`，`api.zhipuai.cn` → `zhipuai`
- 填 `localhost` 或 `127.0.0.1`（本地服务）→ `local`
- 多张卡片撞名会自动加后缀（`bigmodel`、`bigmodel-2`、`bigmodel-3`）
- 测试连接通过后，卡片标题会显示最终标识（如"自定义 · 智谱 (bigmodel)"），以页面上显示的为准

> 提示：连接测试通过后，这家服务的模型才会出现在下面"模型分配"的列表里，可以像精选服务商一样直接选。

## 常见问题
| 问题 | 解决 |
|---|---|
| 双击没反应 | 杀毒软件拦截了 bat，添加信任；或右键"以管理员身份运行" |
| 浏览器没弹出配置页 | 等 3 秒再双击一次；确认 启动.bat 所在路径无中文嵌套过深 |
| API key 无效 | 检查是否复制完整（sk- 开头）、服务商后台是否已充值 |
| 想换模型 | 删掉 data 文件夹重新配置，或直接改 opencode/config 下的文件 |
| 怎么更新 | 等新版整合包发布，解压覆盖（保留 opencode/auth 与 opencode/config/opencode/local 不丢配置） |

## 进阶成长路径
1. 用工作台写你的第一个小工具
2. 学会看 AI 写的代码（让它注释每一行）
3. 自己改 AI 生成的代码（从改一个数字开始）
4. 把 opencode 装进系统 PATH（安装到系统.bat），任何文件夹都能启动
5. 加入 mod 开发社区，用这套环境写你的第一个 SPT mod
