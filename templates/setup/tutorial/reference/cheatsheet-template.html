A会话命令

命令作用
opencode启动交互式 AI 会话
opencode "一句话任务"带初始任务直接启动
exit / quit退出会话
/clear清空当前对话上下文
/model查看或切换当前模型
/help查看全部内置命令

B快捷键

按键作用
Ctrl + `呼出 / 收起终端
Ctrl + C中断当前任务（不是复制）
Ctrl + Shift + C复制选中内容
Ctrl + Shift + V粘贴
↑ / ↓翻阅历史命令
Tab补全路径与文件名

C最小配置示例

opencode.json -- 最小可用配置
> # 复制以下内容保存为 ~/.config/opencode.json
{
  "model": "kimi-code-plan-cn/k3",
  "theme": "vt-os-phosphor",
  "language": "zh-CN"
}

D对话技巧

说法效果
"先别改，只读目录"让 AI 进入只读勘察模式
"分三步做，每步告诉我"把大任务拆成小步，便于检查
"撤销刚才的修改"回滚最近一次写入
"用中文注释"生成的代码注释改为中文

E故障排查

症状速查

  • 提示符消失：任务还在跑，先等 10 秒，再按 Ctrl + C。
  • 中文变乱码：检查配置文件里 "language": "zh-CN" 是否生效。
  • AI 不回应：网络问题居多， /clear 后重试，再不行重启会话。

提示

纸质速查表解决"忘了怎么敲"；在线课程解决"不知道为什么"。两者搭配效率最高。
