LESSON 05

体系地图：五层结构与文件位置

预计 15 分钟 | 难度：进阶 | 前置：第 2 课 · 第 3 课 | 更新于 2026-09 | 适用版本：QDIP 0.6.0（环境快照 2026-09-30） 体系结构

前几课你学了"怎么决策"；这一课给整台机器画一张地图—— 哪一层管什么、文件都在哪。出问题时，你就知道该敲哪扇门。

5.1五层结构

从上到下，规则 → 技能 → 编排 → 本体 → 外援。上面定方向，下面干活：

体系结构 -- 五层
[宪法层]  preferences.md        ← 规则：入口判定 / 会话边界 / 委派
[技能层]  SKILL.md × 48         ← 流程与工具（两处目录）
[编排层]  OMOslim 插件          ← 预设 / 代理 / 模型 / 后台任务
[本体层]  opencode              ← 终端 / 会话 / TUI 命令
[外援层]  MCP                   ← 外部工具（浏览器、Blender…）
  • 宪法层：你写的规则，最终裁决一切流程问题——第 1、2、3 课的判定表都出自这里；
  • 技能层：一叠说明书（grill、spec、fix……），AI 按需加载；
  • 编排层：工头与代理团队的家，也是模型和预设的配置处；
  • 本体层：真正跑在你电脑上的程序——终端界面、会话、命令；
  • 外援层：给 AI 接的外部工具（比如浏览器自动化、Blender 控制）。

改配置的入口

想改这些文件时，不用自己动手——在对话里说一句"帮我改一下配置"， 系统会走第 1 课的配置车道（customize-opencode）， 自动备份、窄修改、提醒你重载生效。第 6 课还会细讲安全改配置的完整套路。

5.3预设与模型

  • 预设（preset）是一整套"代理 × 模型"的组合方案。你当前激活的是 matt-bridge（配你的 Matt 工程流技能）；配置里还存着 DeepSeek-Only、superpowers-bridge 两套备用方案。
  • 切换预设：TUI 里用 /preset——但重载后才生效（这个规律第 6 课还会反复用到）。
  • 每个代理的模型都在预设里逐一定义：搜索类配快模型、决策类配强模型（第 3 课）。
  • 花销与余量：看侧边栏的用量条（opencode-quota 插件提供）——它按服务商显示剩余额度。

5.4一句话任务的旅行

把五层串起来看。你说一句"给整合包做个小工具"，接下来：

  1. 宪法层定路线：入口判定 → 单窗口任务；
  2. 技能层加载对应说明书：grill → implement；
  3. 编排层开始工作：工头拆活，需要时派代理（新会话 = 新工作台）；
  4. 本体层执行：真的读写文件、跑命令、管理会话；
  5. 外援层补短板：需要查文档、看截图时，调用对应工具。

每一层各司其职——所以出问题时，也是按层定位（第 6 课的分诊表就建立在这张地图上）。

5.6立即动手

立即动手 · TRY IT NOW

寻宝练习——亲手把地图走一遍：

  1. 打开 ~/.config/opencode/oh-my-opencode-slim.json，找到 designer 的模型那一行（提示：搜 kimi）；
  2. 在同一个文件里找到当前预设的名字（"preset" 字段）；
  3. 打开 preferences.md，找到"委派规则"一节，认一认你记住的代理名。

5.7小结

三句话记住这一课：五层结构从上到下——宪法 / 技能 / 编排 / 本体 / 外援； 想改什么先查文件地图，别乱翻； 改配置不用手写——走配置车道，它会帮你备份并提醒生效条件。
