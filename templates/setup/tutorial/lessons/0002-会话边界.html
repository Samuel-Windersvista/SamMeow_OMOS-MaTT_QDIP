LESSON 02

会话边界：什么时候该换一张工作台

预计 15 分钟 | 难度：进阶 | 前置：第 1 课 | 更新于 2026-09 | 适用版本：QDIP 0.6.0（环境快照 2026-09-30） 上下文管理

上一课解决"任务从哪条车道进来"；这一课解决"工作在哪张台面上做"。 AI 的记性不是无限的——工作台堆满了，它就开始又慢又糊涂。 好消息是：换台面本身是免费的，前提是你会挑时机。

2.1为什么上下文会"变质"

一个会话就是一张工作台；上下文是台面上摊开的所有材料—— 你的每句话、AI 的每次回答、读过的文件、跑过的命令。台面就那么大， 摊满之后开始出问题，症状固定是这三种：

  • 健忘：你早就说过的约定（"注释用中文""别动那个文件"）忽然不再被遵守；
  • 跑偏：干着干着，目标悄悄漂移，产出和你最初要的不是一回事；
  • 变贵：每一轮它都要重读全部历史，反应越来越慢，花的钱越来越多。

这套体系给单会话定的健康上限约 150K token——你的 preferences.md 把 <150K token 直接写进了"单窗口任务"的定义； ask-matt 技能里把它称为 smart zone 的边界。 到了这个量级，换台不是可选项，是必选项。

为什么重要

这不是某个模型的缺陷，是所有会话式工具的物理规律。应对办法不是"让 AI 更努力"， 而是在正确的时机换台面——把旧台面清掉，让新台面从干净状态开始。 这正是你点名的盲区：上下文管理。

2.2五种换台方式（决策梯）

你的 preferences.md 规定：会话到边界时，按序选第一项合适的。 先问"能不能继续"，再问"能不能干净重启"，然后才是搬迁、外包、压缩——

表 2-1 · 会话边界的五种处理方式（按优先级排序，源自 preferences.md）
方式何时选它代价与操作
1. continue 会话仍是第一手来源：阶段没结束、活没干完 无代价，什么都不用做
2. clear 到了阶段边界，且该落盘的都落盘了 丢掉未落盘的一切；/new 开新会话
3. handoff 仅"搬迁"场景：换 harness、换目录、交同事 要生成并阅读搬迁文档；/handoff 技能
4. subagent 范围足够紧、能 AFK 跑 需把任务包交代清楚；丢后台跑，回来收结果
5. compact 最后手段：不想丢链条又必须腾空间 信息有损；/compact（别名 /summarize）

> 到边界了，怎么换台？

操作速记

开新会话 /new（别名 /clear，快捷键 ctrl+x n）； 找回旧会话 /sessions（别名 /resume）； 压缩 /compact（快捷键 ctrl+x c）。 干净重启不等于烧掉记录——旧会话随时可以从 /sessions 里找回来。

2.3三条铁律

铁律一 · 落盘先于换台

文件是耐久记忆，会话是可抛弃的。spec、工单、笔记、决策记录—— 这些东西写进磁盘之后，会话才允许死。没有落盘就换台，等于把工作台直接掀翻。 看看我们的教学档案：MISSION.md、learning-records/、NOTES.md， 就是为了让每次会话可以干净地结束，而学习不丢。

铁律二 · 边界只在阶段边缘

活干到一半别换台——会话仍是第一手来源，换台就是自断线索。 换台的时机是：阶段结束、工单完成、决策拍板。看一条标准的多窗口节奏：

多窗口任务的标准节奏 -- 边界画在工单之间
grill-with-docs → to-spec → to-tickets   # 同一会话，不中断
──────── 边界：工单已落盘 ────────
implement 工单 1                          # 新会话
──────── 边界 ────────
implement 工单 2                          # 新会话

注意"同一会话，不中断"那行：追问、写 spec、拆工单共享同一份思考链条， 中途换台会丢链条。换台发生在工单落盘之后——每张工单开工时，新会话只读它的工单文档， 台面干净，注意力聚焦。

铁律三 · compact 是最后手段

想腾空间时，先问"能不能 clear"——干净重启没有信息损失； 只有既不能重启、又必须继续同一根链条时，才用 /compact 做有损压缩。

注意

两个方向的误用都很常见：该换不换——台面堆到发臭还硬撑， AI 开始健忘跑偏；不该换乱换——活干到一半开新会话， 又得从头讲一遍背景。判断标准只有一个：现在是阶段边缘吗？东西落盘了吗？

2.5立即动手

立即动手 · TRY IT NOW

  1. 复盘：回想你最近一次长会话——有没有阶段边界被错过？有没有该落盘的东西还留在"脑子里"？
  2. 下次开工时练一次：在阶段边界处主动说一句——"到这里，开新会话，带上这份文档继续。"
  3. 练完把感受告诉我（哪怕只有一句），我们复盘这次换台值不值。

2.6小结

三句话记住这一课：上下文会变质，换台是解药； 决策梯按序选——continue → clear → handoff → subagent → compact； 落盘先于换台——文件是耐久记忆，会话可以死。
