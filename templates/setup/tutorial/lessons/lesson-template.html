LESSON 01

初见你的 VT-OS 终端

预计 20 分钟 | 难度：入门 | 无需任何编程基础 | 更新于 2026-09 环境准备

欢迎来到 OpenCode 终端上手指南。你是一个内容创作者，不是程序员——这很好， 这门课就是为完全零基础的你设计的。今天你只需要学会一件事： 打开终端，敲下第一条命令，看到它回应你。

1.1本课目标

完成本课后，你将能够：

  • 说出终端是什么、它和"聊天窗口"有什么本质区别；
  • 用快捷键 Ctrl + ` 呼出你的 VT-OS 终端；
  • 运行 opencode 启动 AI 编程会话，并读懂提示符 > 的含义；
  • 用 exit 或 Ctrl + C 安全退出。

1.2第一步：打开终端

终端本质上是一个"用文字指挥电脑"的窗口。你在里面输入一行指令， 电脑执行后把结果打印回来。按下 Ctrl + ` （反引号键，数字 1 左边那颗），你的 VT-OS 终端就会从屏幕下方滑出。

VT-OS // TERMINAL -- 第一次启动
> opencode
# 启动交互式 AI 编程会话，稍等数秒
[VT-OS] STATUS: OPERATIONAL | RADIATION: MINIMAL
Welcome, Overseer. 会话已就绪。
> _

为什么重要

后续每一节课都建立在"终端 = 你的驾驶舱"这个认知上。如果你跳过这一课， 第 4 课往后的所有操作都会变成照抄乱码——就像背课文却不识字。

认识提示符 >

每一行开头那个绿色 > 叫做提示符。它表示： "电脑在等你说话"。当 > 后面只有一个闪烁的光标 _ 时，你才可以输入；如果终端正在输出文字，请先等它说完。

提示

输错字不用整行重敲：用 ← → 移动光标， Backspace 删除，Home 直接跳回行首。

1.3本课命令速览

这张表浓缩了本课全部命令，先混个眼熟即可，不必背诵：

表 1-1 · 第 1 课命令一览（完整速查见 reference/ 下的速查表）
命令作用记忆钩子
opencode 启动 AI 编程会话 就是产品名，敲它等于"开机"
exit 退出会话，回到普通终端 出口标志牌上写的就是它
Ctrl + C 中断当前正在运行的任务 C = Cancel（取消）
↑ 调出上一条输入过的命令 向上的箭头 = 回到过去

注意

Ctrl + C 在终端里不是复制！ 它是"立即停止当前任务"。复制请用鼠标选中后 Ctrl + Shift + C。 这是新手最常踩的坑，没有之一。

立即动手 · TRY IT NOW

别只看不练，现在就用 3 分钟完成你的第一次会话：

  1. 按 Ctrl + ` 呼出终端；
  2. 输入 opencode，回车，等待 > 提示符出现；
  3. 输入一句中文指令，例如：帮我新建一个叫做 demo 的文件夹；
  4. 观察 AI 的回复，然后输入 exit 退出。

1.5小结

今天你完成了从"没碰过终端"到"跑通一次 AI 会话"的跨越。 终端不是程序员的专利，它只是另一种对话方式——而你现在会开口了。 命令行的交互范式可以追溯到 1970 年代的 Unix 传统（见延伸阅读 [1]）， 半个世纪不变，正说明它经得起时间考验。

  1. [1] Kernighan & Pike, The Unix Programming Environment, 1984. 命令行文化的源头读物，前三章即可。
  2. [2] OpenCode 官方文档 · 快速上手章节（见上方"一手资料"）。
