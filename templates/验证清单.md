# QDIP 验证清单（玩家 FAQ）

## 5 步上手

1. 解压到任意文件夹（建议在 D:\ 或 E:\ 根目录下**新建一个文件夹**再解压，路径别太深、别带空格）
2. 双击 `启动.bat`
3. 浏览器弹出配置页：勾选模型服务商 → 粘贴 API key → 点"测试连接"（显示成功）
4. 点"保存配置"，关闭浏览器
5. 重新双击 `启动.bat` → 进入工作台

## 常见报错对照

| 现象 | 原因与解决 |
|---|---|
| 测试连接提示"API key 无效（401）" | key 复制不完整，或服务商后台未充值；重新复制以 `sk-` 开头的完整 key |
| 测试连接提示"网络错误" | 本机无法访问该服务商 API（代理/防火墙限制）；检查网络后再试 |
| 浏览器没弹出配置页 | 等 3 秒再双击一次；确认路径无中文嵌套过深 |
| 双击没反应 | 杀毒软件拦截了 bat，添加信任；或右键"以管理员身份运行" |
| 引导页打不开 / 端口被占用 | 关闭其他占用 127.0.0.1 端口的程序后重试 |
| 想换模型服务商 | 删掉 `data` 文件夹重新配置，或直接改 `opencode/config` 下的文件 |

## 重置方法

删除整个 `data` 文件夹 = 回到首次配置状态（配置与 API key 也一起重置）。

## 更新方法

等新版整合包发布，下载新版 zip 解压覆盖到同一目录。保留 `opencode/auth`（登录态）与 `opencode/config/local`（本地配置）可以保留你的设置。

## 提示

- **勿解压至盘符根目录**（如直接解压到 C:\ 或 D:\ 根），请在根目录下新建文件夹再解压
- 首次运行需要联网（测试连接与 AI 对话都要访问模型服务商 API）
