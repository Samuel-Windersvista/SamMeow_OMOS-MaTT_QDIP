### 3.1 宿主兼容性判定：留在 OpenCode v1 + 升级 3.0.x —— 可行，但有明确功能缺口

官方文档 [docs/opencode-v2-compatibility.md](https://github.com/alvinunreal/oh-my-opencode-slim/blob/master/docs/opencode-v2-compatibility.md) 原文（已亲验）：

> oh-my-opencode-slim installs and runs on **both** OpenCode v1 (`opencode`) and OpenCode v2 (`opencode2`) from a single published package.

- **v1 宿主**（≥ v1.17.10；本机 `opencode-ai@1.18.33` 满足）：完整功能走 `server()`；另有一次 "embedded v2 pass"（仅注册用途的子集 context）。
- **v2 宿主**：要求 v2.0.7+，更旧的 v2 不支持。
- 3.0.1 的 [`f8968a4`](https://github.com/alvinunreal/oh-my-opencode-slim/commit/f8968a4) 专门修复 v1 宿主启动崩溃（已亲验：主题 "bug(v2): fix startup crash on OpenCode v1 hosts"，2026-09-29）。

**v1 宿主上的功能缺口（自动降级，无需配置）**：

| 功能 | v1 宿主行为 |
|---|---|
| bundled skills 交付 | **不交付**（in-process 注册需要 `ctx.skill` draft 的 `add`，仅 v2 提供；旧磁盘同步已移除）。既有磁盘副本仍可加载，但不再经此通道更新 |
| marketplace agent 激活 | 不可用（需要 `ctx.session.update`） |
| native ordered permission 策略编译 | 禁用并记录一次性 warning；静态 agent 权限仍生效 |
| 后台任务持久化（`ctx.storage`） | 进程内回退，无持久化 |
| foreground model fallback | 保留历史行为（该功能在 v2 上反被禁用） |
| multiplexer panes | 保持原有支持（v2 侧支持为 3.0.0 新增） |
| `backgroundJobs.boardInjection` 等新配置开关 | 双宿主有效 |

**对既有工作流的关键含义**：你当前由 OMO 交付技能的通路（`.oh-my-opencode-slim/skills-manifest.json` 暂存 + 磁盘副本机制）属于旧世界；3.0.x 将其替换为仅 v2 可用的进程内注册。v1 + 3.0.x 组合下，bundled skills（simplify / codemap / deepwork 等）**不会**再通过插件通道送达或更新，需要手动维护副本。
