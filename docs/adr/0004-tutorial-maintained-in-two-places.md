# 教学站点两处各自维护

教学站点既随整合包分发，又在视频仓库的 `教学` 目录中持续演进——`/teach` 的工作区档案（使命、学习记录、课程迭代）都在那里。整合包需要一个可离线、自包含的构建输入。

决定：**两处各自维护**。视频仓库是教学生产工作区；QDIP 仓库在 `templates/setup/tutorial/` 保存分发包所需的副本，随 `setup/` 目录部署入包。两处不做自动同步；`docs/发布前检查清单.md` 增加「教学同步检查」——发版前核对两处内容是否一致（或确认差异为刻意）。

被否决的替代方案：

- **唯一源 = 视频仓库，构建期复制**：整合包构建直接引用外部仓库路径。否决理由：构建输入不再自包含，跨仓库耦合进流水线。
- **唯一源 = QDIP 仓库，视频仓留副本**：否决理由：`/teach` 工作流（学习记录、使命档案）在视频仓库持续运转，迁入会打断其生命周期。
