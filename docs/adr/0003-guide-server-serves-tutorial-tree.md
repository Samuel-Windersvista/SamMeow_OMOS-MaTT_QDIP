# 引导服务支持子目录：教学站点以目录树入包

教学站点是多层目录树（课程、速查表、样式与脚本分列子目录，站内全用相对链接）。引导服务 `setup/guide-server.js` 原本只服务 `setup/` 下的**单层文件**（`path.basename` 防御路径穿越，MIME 仅 `html`/`js`/`css`），无法托管这种树。

决定：**扩展引导服务的静态路由以支持受控子目录树**——请求路径相对 `setup/` 解析并拒绝越界，教学站点以 `setup/tutorial/` 整树入包；引导页提供一个指向其入口的链接，在新标签页打开。

被否决的替代方案：

- **打平教学**：把教学压成单层文件并重写全部相对链接。否决理由：每次教学更新都要重做打平与链接改写，维护成本高、易错。
- **file:// 直开**：教学随包分发，由启动器用本地文件路径打开。否决理由：浏览器禁止从 http 页面跳转 file:// 链接，入口无法落在引导页内，偏离「在首次设置页提供入口」的需求。
