# 整合包以实装环境为镜像基准

整合包与维护者实装环境的关系定义为**快照镜像**：每次同步后，包内组件版本、技能快照与预设形态应与实装一致；仅剔除机器特定项（`blender-mcp`、本机构建绝对路径）与敏感项（本机凭据文件、实认证目录）。

其中预设模板**连维护者的个人 provider 模型名一并镜像**（如 `kimi-code-plan-cn/*`），作为玩家未配置时的默认值——玩家在引导页配置自己的服务商后，对应 agent 的模型叶子字段会被覆盖。

被否决的替代方案：**分发泛化**——把个人 provider 名替换为通用命名，或仅保留精选服务商。否决理由：与「包=实装」的镜像口径一致优先；模型叶子只是默认值，玩家配置后覆盖，不构成强制绑定。
