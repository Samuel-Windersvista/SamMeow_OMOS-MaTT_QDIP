§1

定位与结构

这个包是什么 · 里面装了什么 · 怎么用

SamMeow QDIP 是一份开箱即用的 AI 编程环境整合包——把 opencode CLI、便携 Node 运行时、插件全家桶与首次配置引导服务组装成一个 zip；玩家解压、双击一个 bat、在浏览器里填一次 API key，就能开始用中文指挥 AI 写代码，全程不需要安装 Node / git / 任何运行时。
