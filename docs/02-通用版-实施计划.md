# QDIP 通用版实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建 QDIP 通用版整合包——绿色 zip 解压即用（opencode + OMOslim + superpowers + matt skills + 便携 Node），玩家双击启动器、引导页填 key 后即可使用。

**Architecture:** 组装式整合包。`tools/build.ps1` 按 `components.json` 清单把本地组件源（OMOslim dist、superpowers、skills、opencode 离线包、便携 Node）组装进 `build/` 目录，配合 `templates/` 下的配置模板与脚本（启动器、引导页、更新脚本）生成 zip。运行时玩家只接触 `启动.bat`：注入环境 → 检测配置标记 → 引导页或直接启动 opencode。配置与组件目录分离（auth/、config/local/、data/ 独立），保证覆盖更新不丢配置。

**Tech Stack:** Windows Batch + PowerShell（打包器）、Node.js 24 LTS（引导服务、便携运行时）、原生 node:test（测试，零依赖）、HTML/JS 单文件引导页。

**Spec:** `E:\云文件\GitHub\SamMeow_OMOS+SP+MaTT_QDIP(Quick Deployment Integration Package)\docs\01-通用版-spec.md`

## Global Constraints

- 目标平台：仅 Windows 10/11（bat + ps1）
- 所有路径可能含空格/中文：bat/ps1 中一律双引号包裹；脚本内部使用相对路径（`%~dp0` 基准），禁止硬编码绝对路径
- 写入的所有文本文件：UTF-8 无 BOM（PowerShell 用 `[System.IO.File]::WriteAllText` + `UTF8Encoding($false)`）
- 便携 Node 版本：24.x LTS zip 版（与开发机 24.14.1 对齐）
- opencode 版本：1.18.25（npm 离线包）
- superpowers：6.3.0；OMOslim：本地仓库 dist 构建产物（2.2.17+patch-kit 合并版）
- zip 内相对路径深度 ≤ 5 层（Windows MAX_PATH 安全）
- 引导服务端口：0（自动分配），端口写入 `data/.guide-url` 供启动器读取
- 测试框架：node:test（内置 node，零 npm 依赖）

  $src = $c.source.Replace('/', '\')
  if (-not (Test-Path -LiteralPath $src)) { $missing += "$($c.name): $src" }

if ($missing.Count -gt 0) {
  Write-Host "[FAIL] missing sources:" -ForegroundColor Red
  $missing | ForEach-Object { Write-Host "  $_" -ForegroundColor Red }
  exit 1

  Write-Host "[OK] all $($json.components.Count) component sources exist"
  exit 0
}

```bat
@echo off
setlocal EnableExtensions
title SamMeow AI 工作台
cd /d "%~dp0"

rem --- 环境注入：便携 Node + opencode CLI ---
set "ROOT=%~dp0"
set "PATH=%ROOT%runtime\node;%ROOT%opencode\bin;%PATH%"
set "XDG_DATA_HOME=%ROOT%opencode\auth"

rem --- 自检模式：验证路径与版本 ---
if /i "%~1"=="--check" (
  echo [check] node: %ROOT%runtime\node\node.exe
  if not exist "%ROOT%runtime\node\node.exe" echo [FAIL] node missing
  if not exist "%ROOT%opencode\bin\opencode.exe" if not exist "%ROOT%opencode\bin\opencode.cmd" echo [FAIL] opencode missing
  "%ROOT%runtime\node\node.exe" --version
  exit /b 0
)

rem --- 首次运行引导 ---
if not exist "%ROOT%data\.configured" (
  if not exist "%ROOT%data" mkdir "%ROOT%data"
  del /q "%ROOT%data\.guide-url" 2>nul
  start "QDIP-Guide" /min "%ROOT%runtime\node\node.exe" "%ROOT%setup\guide-server.js" "%ROOT%"
  rem 等待引导服务写入 .guide-url（最多 15 秒）
  set /a tries=0
  :waitguide
  if not exist "%ROOT%data\.guide-url" (
    set /a tries+=1
    if %tries% GEQ 30 goto guidefail
    timeout /t 0.5 /nobreak >nul
    goto waitguide
  )
  set /p GUIDE_URL=<"%ROOT%data\.guide-url"
  start "" "%GUIDE_URL%"
  echo 首次使用：请在浏览器中完成模型配置，完成后重新双击本文件启动。
  goto :eof
  :guidefail
  echo [FAIL] 引导服务启动失败。请截图本窗口反馈。
  pause
  exit /b 1
)

rem --- 正常启动 opencode ---
opencode %*
exit /b %errorlevel%
```

- [ ] **Step 3: 实现 config-writer.js**

```js
const fs = require('node:fs');
const path = require('node:path');

/** 内置服务商元数据：显示名 + 测试用的模型名（探测连接用最便宜的模型） */
const PROVIDERS = {
  deepseek: { label: 'DeepSeek', testModel: 'deepseek-chat', baseUrl: 'https://api.deepseek.com' },
  kimi: { label: 'Kimi (Moonshot)', testModel: 'moonshot-v1-8k', baseUrl: 'https://api.moonshot.cn/v1' },
  openai: { label: 'OpenAI', testModel: 'gpt-4o-mini', baseUrl: 'https://api.openai.com/v1' },
};

function rootOf(root) {
  return {
    configDir: path.join(root, 'opencode', 'config'),
    authFile: path.join(root, 'opencode', 'auth', 'auth.json'),
    configured: path.join(root, 'data', '.configured'),
  };
}

function configure({ root, providers }) {
  const { configDir, authFile, configured } = rootOf(root);
  fs.mkdirSync(path.dirname(authFile), { recursive: true });
  fs.mkdirSync(configDir, { recursive: true });

  // 1) auth.json（opencode 凭证格式：{ provider: { type: 'api', apiKey } }）
  const auth = {};
  for (const [name, p] of Object.entries(providers)) {
    auth[name] = { type: 'api', apiKey: p.apiKey };
  }
  fs.writeFileSync(authFile, JSON.stringify(auth, null, 2) + '\n', 'utf8');

  // 2) opencode.json：合并 providers 段（模板里 providers: {}）
  const cfgPath = path.join(configDir, 'opencode.json');
  const cfg = JSON.parse(fs.readFileSync(cfgPath, 'utf8'));
  cfg.providers = cfg.providers || {};
  for (const [name, p] of Object.entries(providers)) {
    cfg.providers[name] = { npm: '@ai-sdk/' + name, options: { baseURL: PROVIDERS[name]?.baseUrl } };
  }
  fs.writeFileSync(cfgPath, JSON.stringify(cfg, null, 2) + '\n', 'utf8');

  // 3) 标记
  fs.writeFileSync(configured, JSON.stringify({ at: new Date().toISOString(), providers: Object.keys(providers) }), 'utf8');
}

async function testConnection({ provider, apiKey }) {
  const meta = PROVIDERS[provider];
  if (!meta) return { ok: false, error: `未知服务商: ${provider}` };
  try {
    const res = await fetch(`${meta.baseUrl}/models`, {
      headers: { Authorization: `Bearer ${apiKey}` },
    });
    if (res.ok) return { ok: true };
    if (res.status === 401) return { ok: false, error: 'API key 无效（401）' };
    if (res.status === 402) return { ok: false, error: '余额不足（402）' };
    return { ok: false, error: `HTTP ${res.status}` };
  } catch (e) {
    return { ok: false, error: `网络错误: ${e.message}` };
  }
}

module.exports = { configure, testConnection, PROVIDERS };
```

- [ ] **Step 6: 实现 guide-server.js**

```js
const http = require('node:http');
const fs = require('node:fs');
const path = require('node:path');
const { configure, testConnection, PROVIDERS } = require('./config-writer');

const root = path.resolve(process.argv[2] || '.');
const dataDir = path.join(root, 'data');
const setupDir = path.join(root, 'setup');

const MIME = { '.html': 'text/html; charset=utf-8', '.js': 'text/javascript; charset=utf-8', '.css': 'text/css; charset=utf-8' };

const server = http.createServer(async (req, res) => {
  const url = new URL(req.url, 'http://127.0.0.1');
  try {
    if (url.pathname === '/api/status') {
      res.writeHead(200, { 'Content-Type': 'application/json' });
      res.end(JSON.stringify({ ok: true, providers: PROVIDERS, configured: fs.existsSync(path.join(dataDir, '.configured')) }));
      return;
    }
    if (url.pathname === '/api/configure' && req.method === 'POST') {
      let body = '';
      for await (const chunk of req) body += chunk;
      const { providers } = JSON.parse(body);
      configure({ root, providers });
      res.writeHead(200, { 'Content-Type': 'application/json' });
      res.end(JSON.stringify({ ok: true }));
      return;
    }
    if (url.pathname === '/api/test' && req.method === 'POST') {
      let body = '';
      for await (const chunk of req) body += chunk;
      const { provider, apiKey } = JSON.parse(body);
      const result = await testConnection({ provider, apiKey });
      res.writeHead(200, { 'Content-Type': 'application/json' });
      res.end(JSON.stringify(result));
      return;
    }
    // 静态文件：仅允许 setup 目录内
    const rel = url.pathname.replace(/^\/setup\//, '');
    const file = path.join(setupDir, path.basename(rel));
    if (fs.existsSync(file) && fs.statSync(file).isFile()) {
      res.writeHead(200, { 'Content-Type': MIME[path.extname(file)] || 'application/octet-stream' });
      res.end(fs.readFileSync(file));
      return;
    }
    res.writeHead(404); res.end('not found');
  } catch (e) {
    res.writeHead(500, { 'Content-Type': 'application/json' });
    res.end(JSON.stringify({ ok: false, error: e.message }));
  }
});

server.listen(0, '127.0.0.1', () => {
  const port = server.address().port;
  fs.mkdirSync(dataDir, { recursive: true });
  fs.writeFileSync(path.join(dataDir, '.guide-url'), `http://127.0.0.1:${port}/setup/first-run.html`, 'utf8');
});
```

**Interfaces:**

- [ ] **Step 1: 编写 build.ps1**

```powershell
param(
  [string]$ComponentsFile = "$PSScriptRoot\components.json",
  [switch]$SkipZip
)
$ErrorActionPreference = 'Stop'
$root = Split-Path $PSScriptRoot -Parent
$json = Get-Content $ComponentsFile -Raw -Encoding UTF8 | ConvertFrom-Json
$version = $json.version
$outDir = Join-Path $root "build\qdip-generic-$version"
$templates = Join-Path $root "templates"

Write-Host "[1/5] 清理组装目录"
if (Test-Path $outDir) { Remove-Item $outDir -Recurse -Force }
New-Item -ItemType Directory -Path $outDir -Force | Out-Null

Write-Host "[2/5] 复制组件"
foreach ($c in $json.components) {
  $src = $c.source.Replace('/', '\')
  $dst = Join-Path $outDir ($c.target.Replace('/', '\'))
  New-Item -ItemType Directory -Path (Split-Path $dst -Parent) -Force | Out-Null
  Copy-Item -LiteralPath $src -Destination $dst -Recurse -Force
  Write-Host "  + $($c.name) -> $($c.target)"
}

Write-Host "[3/5] 部署模板"
Copy-Item "$templates\启动.bat" "$outDir\启动.bat" -Force
Copy-Item "$templates\更新组件.bat" "$outDir\更新组件.bat" -Force
New-Item -ItemType Directory -Path "$outDir\setup" -Force | Out-Null
Copy-Item "$templates\setup\*" "$outDir\setup" -Recurse -Force
New-Item -ItemType Directory -Path "$outDir\opencode\config" -Force | Out-Null
Copy-Item "$templates\opencode.json" "$outDir\opencode\config\opencode.json" -Force
Copy-Item "$templates\oh-my-opencode-slim.json" "$outDir\opencode\config\oh-my-opencode-slim.json" -Force
New-Item -ItemType Directory -Path "$outDir\opencode\auth" -Force | Out-Null
New-Item -ItemType Directory -Path "$outDir\data" -Force | Out-Null
New-Item -ItemType File -Path "$outDir\data\.gitkeep" -Force | Out-Null

Write-Host "[4/5] 校验"
$check = & "$PSScriptRoot\check-sources.ps1" -ComponentsFile $ComponentsFile
$nodeOk = Test-Path "$outDir\runtime\node\node.exe"
$ocOk = (Test-Path "$outDir\opencode\bin\opencode.exe") -or (Test-Path "$outDir\opencode\bin\opencode.cmd")
if (-not $nodeOk) { throw "缺少便携 Node：请将 node-v24.14.1-win-x64 放入 tools/cache/ 并按 components.json 命名" }
if (-not $ocOk) { throw "缺少 opencode CLI：请先执行 npm pack opencode-ai@1.18.25 并解包到 tools/cache/opencode-1.18.25" }
Write-Host "  [OK] node: $nodeOk  opencode: $ocOk"

Write-Host "[5/5] 打包 zip"
if (-not $SkipZip) {
  $zip = Join-Path $root "build\qdip-generic-$version.zip"
  if (Test-Path $zip) { Remove-Item $zip -Force }
  Compress-Archive -Path "$outDir\*" -DestinationPath $zip -CompressionLevel Optimal
  Write-Host "  -> $zip"
}
Write-Host "[DONE] 组装完成: $outDir"
```

```markdown
# SamMeow AI 工作台 — 玩家使用指南

## 这是什么
一个开箱即用的 AI 编程环境（opencode + 插件全家桶）。你负责描述需求，AI 负责写代码。

## 快速开始（5 步）
1. 解压到任意文件夹（路径别带中文以外的问题：建议 D:\ 或 E:\ 根目录新建文件夹）
2. 双击 启动.bat
3. 浏览器弹出配置页：勾选模型服务商 → 粘贴 API key → 点"测试连接"（显示成功）
4. 点"保存配置"，关闭浏览器
5. 重新双击 启动.bat → 进入工作台

## 怎么高效使用（工作流建议）
### 1. 一个项目一个文件夹
每个想法建一个独立文件夹（比如 D:\我的项目\子弹价格修改器），不要把多个项目混在一起。
AI 会在当前文件夹里读写文件，项目隔离 = 修改互不干扰。

### 2. 先想清楚再开口（需求描述公式）
好的需求 = 做什么 + 给谁用 + 边界。
- 差的：帮我写个工具
- 好的：做一个给 SPT 用的工具，把 mods 文件夹里所有 json 的 "price" 字段统一打 8 折，保留原始文件备份

### 3. 让 AI 先给你方案，再让它动手
第一次对话先说"先给我一个方案/计划"，确认方向后再说"按这个做"。
方向错了返工的成本远高于多问一句。

### 4. 改不动了就说"看看哪里出问题了"
遇到报错直接把报错文字复制给 AI，说"这个报错什么意思，怎么修"。
不要自己猜，不要重开新对话——同一对话里 AI 记得上下文。

### 5. 重要东西随手备份
AI 写的代码也是代码，重要项目定期复制一份文件夹。
工作台本身的重置很简单：删除 data 文件夹 = 回到初始状态（配置也重置）。

## 适合做什么
- 小工具/脚本（批量改文件、整理数据、自动下载）
- 游戏 mod 配置（改数值、加物品、调平衡）
- 学习编程（让 AI 解释它写的每行代码）
- 数据处理（CSV/JSON/Excel 转换）

## 不适合做什么（现阶段）
- 大型商业软件（涉及复杂架构的项目需要专业开发）
- 涉及别人账号密码/支付系统的程序（安全风险，别让 AI 写）

## 常见问题
| 问题 | 解决 |
|---|---|
| 双击没反应 | 杀毒软件拦截了 bat，添加信任；或右键"以管理员身份运行" |
| 浏览器没弹出配置页 | 等 3 秒再双击一次；确认 启动.bat 所在路径无中文嵌套过深 |
| API key 无效 | 检查是否复制完整（sk- 开头）、服务商后台是否已充值 |
| 想换模型 | 删掉 data 文件夹重新配置，或直接改 opencode/config 下的文件 |
| 怎么更新 | 等新版整合包发布，解压覆盖（保留 opencode/auth 与 opencode/config/local 不丢配置） |

## 进阶成长路径
1. 用工作台写你的第一个小工具
2. 学会看 AI 写的代码（让它注释每一行）
3. 自己改 AI 生成的代码（从改一个数字开始）
4. 把 opencode 装进系统 PATH（安装到系统.bat），任何文件夹都能启动
5. 加入 mod 开发社区，用这套环境写你的第一个 SPT mod
```
